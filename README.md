# Clock Experiment

A flashy, dependency-free binary clock built with plain HTML, CSS and JavaScript.

## Included

- Live binary clock for **HH:MM:SS**, with every digit rendered as 4-bit LEDs.
- Large digital readout alongside the binary matrix.
- 12/24-hour mode.
- Animated second-progress ring and Unix epoch bitstream.
- Four neon themes: Cyber, Aurora, Ember and Void.
- CRT scanlines, procedural starfield, glow, glass panels and responsive layout.
- Pause/resume, fullscreen, and keyboard shortcuts.
- No framework, package manager, build step or external dependency.

## Keyboard

- **Space** — pause/resume
- **F** — fullscreen
- **M** — switch 12/24-hour mode
- **T** — cycle theme
